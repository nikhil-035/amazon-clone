# 🛒 Amazon Clone

A simple **Amazon homepage clone** built using HTML and CSS.

## 🚀 Features

* Amazon-style navigation bar
* Search bar
* Product/category boxes
* Hero section
* Responsive layout
* Font Awesome icons
* Clean and simple UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 📸 Project Preview

This project recreates the look and feel of an Amazon-style shopping homepage for learning and practice.

## 🎯 Purpose

This project was created to practice **HTML, CSS, responsive design, and frontend development**.
